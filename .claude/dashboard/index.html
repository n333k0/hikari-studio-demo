Qué estás mirando

Un tablero en vivo del repositorio: cada tarjeta es una unidad de trabajo y la columna dice en qué estado está. Se recalcula solo cada 5 segundos desde git y el sistema de archivos — nada acá es una captura vieja.

Por hacer
Ítems de docs/KANBAN.md que nadie tomó.
Trabado
Espera una decisión tuya o que se destrabe otra cosa.
En curso
Agentes trabajando ahora + cambios sin commitear.
Para revisar
Un agente terminó y dejó trabajo sin mergear, o se colgó con el worktree trabado.
Listo
Commits recientes en main y agentes que ya cerraron.

Sesiones y agentes no son lo mismo. Una sesión es una ventana de Claude Code; se cuenta porque un hook PostToolUse le refresca el heartbeat en .agent-state/captains/ con cada herramienta que usa, y se apaga sola a los 20 min de quedarse quieta. Un agente es un worker despachado a su propio git worktree bloqueado. 0 agentes no significa que nadie esté trabajando — mirá el conteo de sesiones y la columna En curso.

Lo que este panel NO puede ver: una sesión que se abrió antes de que existiera el hook (los hooks se cargan al arrancar la sesión) no aparece hasta que se reinicia, y una que no tocó nada en 20 min tampoco. No existe API para "listar ventanas de chat abiertas"; solo se cuenta lo que deja huella en el disco.

Clic en cualquier tarjeta para ver el detalle crudo (git log, git status, el claim del agente). Esc cierra.
